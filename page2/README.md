# StudyFlashCards (Update)

This project is a flashcard web app made for school. It helps users study by flipping cards, marking what they know, and tracking progress through a deck.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Open a terminal in the `page2` folder.
2. Run `npm install` to install dependencies.
3. Run `npm start` and open `http://localhost:3000` in your browser.

Instructions for using the software:

1. On the Home page, click **Push to Start Studying**.
2. Click the card to flip between question and answer.
3. Use **Known**, **Review**, **Prev**, **Next**, **Shuffle**, and **Reset** while studying.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Node.js (recommended: latest LTS)
* Express (listed in `package.json`)
* EJS (listed in `package.json`)
